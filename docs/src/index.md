## Introduction

ComModeForecasting.jl is a Julia package for forecasting and nowcasting COVID-19 hospitalizations using pathogen genome concentrations. [ComModeForecasting.jl Package License](@ref license)

## Features

- Comprehensive library of Bayesian models
- Simulation of infectious disease 
- Model calibration
- Sensitivity analysis and uncertainty quantification?
- Visualization of results and MCMC evaluations(live?)

## Installation

To install ComModeForecasting.jl, you can use the Julia package manager. Open the Julia REPL and run the following command:

```julia
using Pkg
Pkg.add("https://github.com/cbernalz/ComModeForecasting.jl.git")
```
